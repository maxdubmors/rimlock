# rimlock

A browser extension for Chrome and Firefox that fills and manages passwords from your own KeePass database, keeping the `.kdbx` file as the single source of truth.

Status: specified, not yet implemented. The spec starts at [`docs/spec/README.md`](docs/spec/README.md); the implementation plan is [`docs/spec/plan.md`](docs/spec/plan.md). Privacy policy: [`PRIVACY.md`](PRIVACY.md).

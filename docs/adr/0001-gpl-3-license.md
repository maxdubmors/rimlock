rimlock is open source and will ship on the Chrome Web Store and AMO. We chose GPL-3.0 over MIT/Apache-2.0 so we can reuse code from the GPL-licensed prior art (Bitwarden clients' autofill heuristics, KeePassXC-Browser, KeeWeb). Years of form-detection edge cases are worth more than permissive licensing for downstream reuse. This is hard to reverse once GPL code has been incorporated.
